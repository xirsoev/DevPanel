# DevPanel

DevPanel — небольшая панель управления проектами на PHP и MySQL. Приложение помогает собрать проекты в одном месте, видеть их статус и прогресс, а также просматривать задачи и активность рабочего пространства.

## Возможности

- регистрация первого администратора и защищённый вход;
- просмотр сводки по проектам, задачам и клиентам;
- создание, просмотр и удаление проектов;
- статусы проектов: планирование, в работе, на паузе и завершён;
- отображение прогресса, сроков и информации о клиенте;
- CSRF-защита форм и безопасное хранение паролей через `password_hash()`;
- адаптивный светлый интерфейс для компьютера и телефона;
- лёгкие анимации с поддержкой `prefers-reduced-motion`.

## Стек

- PHP 8.1+;
- MySQL 8+ или MariaDB 10.4+;
- PDO MySQL;
- HTML, CSS и небольшой JavaScript без фреймворков.

## Запуск локально

1. Запустите MySQL или MariaDB.
2. Создайте базу и таблицы из файла [`database/database.sql`](database/database.sql):

   ```bash
   mysql -u root -p < database/database.sql
   ```

3. Проверьте настройки подключения в [`config/database.php`](config/database.php). По умолчанию используются:

   - хост: `127.0.0.1`;
   - база: `devpanel`;
   - пользователь: `root`;
   - пароль: пустой.

4. Запустите встроенный сервер PHP из каталога проекта:

   ```bash
   php -S 127.0.0.1:8000
   ```

5. Откройте [`http://127.0.0.1:8000/register.php`](http://127.0.0.1:8000/register.php) и создайте первый аккаунт администратора. После этого используйте страницу входа [`login.php`](login.php).

## Структура проекта

```text
config/              подключение к БД и авторизация
database/            SQL-схема и начальные данные
pages/projects/      список проектов и карточка проекта
assets/css/          стили интерфейса
assets/js/           JavaScript для форм авторизации
index.php            главная панель
login.php            вход
register.php         регистрация первого администратора
logout.php            выход
```

## Безопасность

Для рабочего сервера используйте HTTPS, отдельного пользователя MySQL с ограниченными правами, секреты через переменные окружения и регулярные резервные копии базы данных.
